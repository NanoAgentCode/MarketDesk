## 1.7.9 免费多源交叉验证

- 无账号、无交易功能，继续使用免费公开行情接口；自动尝试 Yahoo、东方财富、腾讯财经。来源下拉仍是原有Y/E/F，作为首选源；腾讯作为自动核验/备用源。
- 纳斯达克综合、纳斯达克100、恒生科技：Yahoo＋腾讯；沪深股票/ETF：东方财富＋Yahoo＋腾讯。中证港股通创新药931250和场外基金估算目前仅有一个已映射来源，不用其他指数/ETF代替。
- 每批并行取数，按实际服务商去重。同一服务商的多个备用接口不算多个来源。备用源缓存最多60秒，以降低限流压力；行情本身的延迟仍可能超过缓存时间。
- 相同单位且行情时间差不超过2分钟，或超过24小时且同日的历史行情，才核对价格和涨跌幅。价格相对容差0.1%，涨跌幅绝对容差0.05个百分点。状态包括单源可用、多源一致、多源有差异、时间或口径不齐。
- 不对差异报价取平均，采用有效数据中时间最新的一份并保留核验状态；差异可能来自延迟、昨收口径或数据问题，不能直接认定哪家错误。多个网站也可能共享上游，一致不等于独立交易所认证。
- 自选「更多」显示核验时间、各来源价格/涨跌幅/行情时间及失败原因；小组件与App预览同时显示简短核验标记。全源失败时保留旧缓存和失败提示。
- 实际应用Java联网测试：两只纳指、恒生科技、国泰电网ETF及华安黄金ETF均为Yahoo/腾讯双源一致；ETF数据时间为9月30日。创新药指数的东方财富接口本次失败，不能宣称有多源核验。

## 构建与安装

1. 用 Android Studio 打开本目录，使用 JDK17，安装 Android SDK Platform 35，等待 Gradle 同步。
2. 在 Build 菜单生成 APK；或 SDK 已配置时执行 `powershell -ExecutionPolicy Bypass -File .\build.ps1`（首次下载 Gradle8.9）。SDK 路径可通过 Android Studio 生成的 local.properties 或 ANDROID_HOME 配置。
3. 安装 `MarketDesk-1.9.0-debug.apk`，打开“行情桌面” → 「桌面」 → 「添加到桌面」。如果系统未弹窗，使用该页「查看添加指引」，在手机桌面的小部件列表里手动添加。开发版 APK 使用调试签名，正式分发应使用自己的发布签名。

## 使用

- 小部件标题打开 App；底部点击刷新；拉高小部件可显示更多条目（最多10条）。所有实例共享自选，App 最多保存20项。
- 默认使用 WorkManager 约15分钟刷新，系统可能延后。手动刷新也需有网络。
- 盯盘从 App 主动开启，常驻通知，每次请求完成后间隔60秒再次刷新；最长2小时，可随时结束。不是交易所推送或秒级实时行情。Android15 对 dataSync 前台服务每天累计时长有限制，系统超时会停止服务。
- 行情显示北京时间、涨跌幅和来源。网络失败保留缓存并标记。场外基金仅为第三方估算，可能无数据或停止提供；不当作正式净值。
- 支持 Yahoo 符号（Y:）、东方财富市场代码（E:）、天天基金代码（F:）。代码示例见 App。黄金 GC=F 为期货，并非国内实物黄金报价。
- HyperOS 如限制后台，请在手机应用设置中检查自启动及省电策略。设置不能保证后台秒级更新。

## 数据与验证边界

使用公开网页行情接口，非有 SLA 的商业行情服务。Yahoo 在部分网络可能不可达；东方财富及天天基金可能限流、调整字段或下线。港股通创新药指数的 `E:2.931250` 市场映射已通过东方财富行情页面和实际分时返回核验；缺失时明确显示失败，不替换成ETF。

当前项目已配置本地编译环境：使用现有 `D:/Program Files/jdk/17` 的 JDK17，Gradle8.9 和 Android SDK35 安装在 `.tools` 内。执行 `powershell -ExecutionPolicy Bypass -File .\build.ps1` 构建，首次依赖下载需要联网。未完成红米真机验证。纳斯达克综合指数和港股通创新药指数接口已取得实际响应；其他品种仍需逐项核验。

真机验收：核对五项代码、币种及昨收涨跌幅；断网检查缓存标记；点刷新并对照行情时间；启动/停止盯盘；拉伸小部件；重启后检查后台任务；测试跨时区及休市显示。

参考：Android 小部件后台刷新 https://developer.android.com/develop/ui/views/appwidgets/advanced ，前台服务限制 https://developer.android.com/develop/background-work/services/fgs/timeout 。
