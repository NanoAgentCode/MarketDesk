## 构建与安装

1. 用 Android Studio 打开本目录，使用 JDK17，安装 Android SDK Platform 35，等待 Gradle 同步。
2. 在 Build 菜单生成 APK；或 SDK 已配置时执行 `powershell -ExecutionPolicy Bypass -File .\build.ps1`（首次下载 Gradle8.9）。SDK 路径可通过 Android Studio 生成的 local.properties 或 ANDROID_HOME 配置。
3. 安装 `MarketDesk-1.7-debug.apk`，打开“行情桌面” → 「桌面」 → 「添加到桌面」。如果系统未弹窗，使用该页「查看添加指引」，在手机桌面的小部件列表里手动添加。开发版 APK 使用调试签名，正式分发应使用自己的发布签名。

## 使用

- 小部件标题打开 App；底部点击刷新；拉高小部件可显示更多条目（最多10条）。所有实例共享自选，App 最多保存20项。
- 默认使用 WorkManager 约15分钟刷新，系统可能延后。手动刷新也需有网络。
- 盯盘从 App 主动开启，常驻通知，每次请求完成后间隔60秒再次刷新；最长2小时，可随时结束。不是交易所推送或秒级实时行情。Android15 对 dataSync 前台服务每天累计时长有限制，系统超时会停止服务。
- 行情显示北京时间、涨跌幅和来源。网络失败保留缓存并标记。场外基金仅为第三方估算，可能无数据或停止提供；不当作正式净值。
- 支持 Yahoo 符号（Y:）、东方财富市场代码（E:）、天天基金代码（F:）。代码示例见 App。黄金 GC=F 为期货，并非国内实物黄金报价。
- HyperOS 如限制后台，请在手机应用设置中检查自启动及省电策略。设置不能保证后台秒级更新。
