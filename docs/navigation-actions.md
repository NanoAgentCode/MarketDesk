# 底部导航与二级操作菜单

“自选 / 桌面 / 设置”固定在 App 底部。点击其他入口切换页面；再次点击当前选中的入口，在按钮上方打开该页面的操作菜单。选中入口旁的 `▴` 表示有二级操作。

| 底部入口 | 二级操作 |
|---|---|
| 自选 | 刷新、编辑自选列表 |
| 桌面 | 编辑自选列表、切换预览小部件、添加到桌面、查看添加指引 |
| 设置 | 编辑自选/基金/ETF、添加常用标的、刷新间隔、开启或结束盯盘、应用系统设置、基金管理 |

设置菜单精简为六项。“编辑自选/基金/ETF”使用同一个表格编辑入口；盯盘未运行时显示“开启盯盘”，运行时显示“结束盯盘”；“基金管理”直接打开手动基金查询，不再增加一层选择菜单。

指定五只基金的批量添加功能已移除。已有自选、市场备注和缓存不作删除；用户仍可通过六位代码查询添加基金，或在表格中编辑。已知基金的类型标签由独立展示元数据保留。

页面保留行情、预览、状态与说明，原来的整页操作按钮移入菜单。每只标的的“更多”、持仓明细以及预览内部的小部件交互仍是内容自身的入口。

操作菜单使用原生 PopupMenu，锚定底部按钮，超出可用高度时由系统提供滚动。点空白区域或返回键可以收起菜单；切换页面、App 进入后台或销毁时也会关闭。再次点击当前入口不会重置页面滚动位置。

`ui/PageActions` 管理菜单项与页面对应关系，`ui/PageActionMenu` 负责展示与关闭，`MainActivity` 将选中操作交给现有刷新、编辑、小组件、盯盘与基金处理逻辑。刷新间隔菜单显示当前保存值。

底部导航与滚动内容在布局上分离，给导航和系统手势区留出空间。原有功能和数据流程保持不变，没有新增运行时框架。

自动验证覆盖底部布局、页面操作完整性、再次点击行为、菜单 ID 和刷新间隔标题。手机上菜单位置、滚动与系统手势的最终效果仍需真机验收。
